적용 시스템IP담보 자동대출 플랫폼 웹 서비스(https://iploan.mustree.kr)와 Mustsem 블록체인(Chain ID 7601)에 배포된 대출 관리 계약. 2026년 10월 22일 배포 버전 기준
적용 대상NH농협은행 여신담당자, IP 가치평가기관 평가사, 플랫폼 운영자·관리자

목적

이 매뉴얼은 LLM·블록체인 기반 IP담보 자동대출 시스템의 시범운영(실증)에 참여하는 기관이 같은 절차와 기준으로 업무를 처리하도록 업무 프로세스를 정한다. 여신담당자의 심사·승인 업무, IP 가치평가기관과의 협업 절차, 장애와 보안사고가 났을 때의 대응 절차를 다룬다.

시범운영 전제

  • 시범운영 단계에서는 대출금 지급과 상환금 수납이 이 시스템을 통해 이루어지지 않는다. 시스템은 승인·상환 사실을 블록체인에 기록하며, 실제 자금 거래는 은행의 기존 시스템과 절차를 따른다.
  • 평가 SBT와 채권 NFT는 업무 처리 이력을 나타내는 기록용 토큰이다. 그 자체로 법적 채권이나 담보권을 표시하지 않는다.
  • 담보인정비율(LTV) 기준 70%는 현재 배포된 계약에 설정된 시범운영 값이다. 기준을 바꾸려면 계약을 다시 배포해야 한다.
  • 협의안 표시가 있는 항목(처리 기한, 비상 등급별 보고 시한, 점검 주기 등)은 실증 협약 과정에서 참여기관이 확정한다.
  • 화면 예시는 가상 데이터로 구성했다. 기업명·지갑 주소·금액·보고서 내용은 실제와 관계없다.
