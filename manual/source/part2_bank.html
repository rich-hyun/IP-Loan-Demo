CHAPTER 2 · 여신담당자
NH농협은행 여신담당자 업무 매뉴얼

평가사가 확정하고 스마트컨트랙트 자동심사를 통과한 신청을 검토해 최종 승인 또는 거절을 결정하고, 승인 건의 상환 내역을 기록하는 절차를 설명한다.

2.1업무 범위와 권한

여신담당자는 자동심사(LTV 70% 이하)를 통과한 신청의 여신 여부를 판단한다. 시스템이 자동으로 판정하는 것은 LTV 기준뿐이므로, 신용·재무·권리관계 판단과 대출 조건 결정은 은행 여신 규정에 따라 여신담당자가 한다.

업무가능 시점조건
심사 정보·평가보고서 열람자동심사 통과(Eligible) 이후웹 화면 열람. 보고서·근거자료는 별도 서명 없이 열린다
최종 승인 또는 거절Eligible 상태에서 1회신청에 배정된 은행 지갑, BANK_ROLE 보유
상환 기록승인(Approved) 이후 완납 전배정된 은행 지갑
원본 특허 PDF 열람승인·완납(Approved·Repaid) 이후배정된 은행 지갑의 서명, 채권 NFT 보유
채권 NFT 지갑 추가승인 이후배정된 은행 지갑
배정 지갑 확인 대출 신청 리스트에는 모든 신청이 보이지만 승인·거절·상환 기록은 신청별로 배정된 은행 지갑만 실행할 수 있다. 배정 지갑은 대출 심사 화면의 블록체인 기록·상환 영역에 있는 여신심사자 · 은행 수령 주소에서 확인한다.

2.2화면 구성

역할을 여신심사역 · NH농협은행으로 선택하면 왼쪽 메뉴에 대시보드, 대출 신청 리스트, 대출 심사가 표시된다.

메뉴용도
대시보드전체 신청의 상태별 건수와 최근 신청 건
대출 신청 리스트전체 신청 목록. 차주기업명·신청번호 검색, 상태별 필터. 행을 누르면 대출 심사 화면에서 그 건이 열린다
대출 심사심사 대기 목록과 심사 화면. 최종 승인·거절, 상환 기록, 원본 열람을 이 화면에서 처리한다
메뉴 — 대출 심사 심사 대기 목록 — 심사중·처리 완료 건 심사 요약 — 금액·담보가치·LTV·신용등급 스마트컨트랙트 자동심사 조건 결정 버튼 — 최종 승인·최종 거절·체인 확인·복구 결과 배너 — 현재 심사 결과 현재 역할 표시와 역할 전환

심사 화면 아래쪽에는 블록체인 기록·상환(온체인 상태, 채권 NFT 번호, 상환 합계, 배정 은행 주소), 평가 확정 정보와 재무 참고 점검, 승인 후의 채권 NFT 카드가 이어진다.

2.4심사 대기 건 확인

  1. MetaMask에서 본인(은행 담당) 지갑을 선택하고, 웹 화면 역할을 여신심사역 · NH농협은행으로 선택한다.
  2. 왼쪽 메뉴에서 대출 심사를 누른다. 심사 대기 목록에 자동심사를 통과한 건(심사중)과 처리를 마친 건(승인·거절)이 표시된다.
  3. 상태가 심사중인 건을 선택한다.
  4. 화면 아래 블록체인 기록·상환 영역의 여신심사자 · 은행 수령 주소가 본인 지갑 주소와 같은지 확인한다. 다르면 다른 담당자에게 배정된 건이므로 처리하지 않는다.
배정 알림 시스템에는 배정 알림 기능이 없다. 운영사가 신규 배정 건을 따로 알리고(3.7절), 여신담당자는 영업일마다 1회 이상 심사 대기 목록을 확인한다. 협의안

LTV 기준을 넘어 자동 거절된 건은 은행 심사 목록에 나타나지 않는다. 평가 중인 건의 진행 상태는 대출 신청 리스트에서 확인한다.

2.8최종 승인·거절

최종 승인

  1. 2.7절 체크리스트와 은행 내부 승인 절차를 마친다.
  2. MetaMask에서 배정된 은행 지갑이 선택되어 있는지 확인한다.
  3. 대출 심사에서 해당 건을 고르고 MetaMask 최종 승인·채권 NFT 발급을 누른다.
  4. 확인 창에서 확인을 누른다.
  5. MetaMask 거래 창에서 네트워크(Mustsem)와 가스 요금을 확인하고 승인한다.
  6. 거래가 확정되면 은행 채권 NFT 발급 완료 알림이 뜨고, 결과 배너가 최종 승인 완료로 바뀌며 채권 NFT 번호가 표시된다.

최종 거절

  1. 거절 사유를 은행 내부 시스템에 먼저 기록한다. 플랫폼에는 거절 사유 입력란이 없다.
  2. MetaMask 최종 거절 → 확인 창 확인 → MetaMask 거래 승인 순서로 처리한다.
  3. 최종 거절 기록 완료 알림 후 결과 배너가 최종 심사 결과 — 거절로 바뀐다. 채권 NFT는 발급되지 않는다.
  4. 차주에게 결과와 사유를 은행 절차에 따라 알린다.
결정은 되돌릴 수 없다 최종 승인·거절은 블록체인에 기록되며 취소할 수 없다. 같은 건을 다시 승인하거나 거절할 수도 없다. 버튼을 누르기 전에 신청번호와 기업명을 다시 확인한다.
화면이 바뀌지 않을 때 MetaMask에서 거래를 승인한 뒤 화면이 바뀌지 않으면 같은 버튼을 다시 누르지 않는다. 체인 확인·복구를 눌러 블록체인 기록을 다시 읽는다(4.4절 A2·A6).

2.9승인 후 관리: 채권 NFT·원본 열람

승인하면 배정된 은행 지갑에 대출채권 NFT가 발급된다. 카드에는 Token ID, 현재 소유 지갑, 토큰 계약 주소, 네트워크가 표시된다.

  • MetaMask에 추가를 누르면 지갑의 NFT 목록에 추가된다. MetaMask의 'NFT 미디어 표시' 설정이 꺼져 있으면 이미지 없이 표시된다.
  • 시범운영 계약에서는 채권 NFT를 다른 지갑으로 옮길 수 없다. 완납 후에도 은행 지갑에 남는다.
  • 은행 원본 열람을 누르고 MetaMask 서명을 하면 차주가 제출한 원본 PDF가 내려받아진다. 승인·완납 상태의 배정 은행 지갑만 열람할 수 있고, 서명 요청은 5분 동안 한 번만 유효하다.

2.10상환 기록

상환금 수납은 은행 시스템에서 처리하고, 수납이 확인된 내역만 플랫폼에 기록한다.

  1. 은행 시스템에서 상환금 입금을 확인한다.
  2. 상환 기록 추가에 상환금액(원)과 상환 참조번호를 입력한다. 참조번호는 은행 거래번호처럼 건마다 다른 값을 쓴다(예: REP-2026-001).
  3. MetaMask로 상환 기록만 추가 → 확인 창 → MetaMask 거래 승인 순서로 처리한다.
  4. 상환 기록 합계와 남은 원금이 갱신된다. 누적 상환액이 신청금액과 같아지면 상태가 완납(Repaid)으로 바뀌고 완납 기록 완료가 표시된다.
구분규칙
금액남은 원금 이하의 양의 정수(원). 남은 원금을 넘는 금액은 기록되지 않는다.
참조번호같은 신청에서 이미 쓴 참조번호는 거부된다(이미 기록된 상환 참조번호입니다.).
기록 범위원금만 기록한다. 이자·연체는 기록하지 않는다.
정정기록한 상환은 취소·수정할 수 없다. 입력 전에 금액을 다시 확인한다(오기록 시 4.4절 E3).
완납 후채권 NFT는 은행 지갑에 그대로 남는다.

2.11유의사항과 자주 묻는 질문

유의사항

  • 승인·거절·상환 기록은 거래마다 가스(MST)가 든다. 잔액이 부족하면 운영사에 충전을 요청한다.
  • 심사 화면의 신용등급·재무정보는 신용정보에 준해 관리한다. 화면 캡처나 보고서 파일을 업무 목적 외로 공유하지 않는다.
  • 배정된 담당자는 바꿀 수 없다. 장기 부재가 예정되면 미리 운영사에 알리고 진행 중인 건을 처리한다(4.4절 E4).
  • 여신담당자의 판단 결과(승인 조건, 거절 사유, 체크리스트)는 은행 내부 시스템이 공식 기록이다. 플랫폼에는 결정 사실만 남는다.
