CHAPTER 1 · 공통
시스템 및 업무 개요

모든 참여기관이 공통으로 알아야 할 서비스 구조, 참여 주체, 업무 흐름과 상태 체계, 지갑·네트워크 준비 방법, 보안 수칙을 설명한다.

1.1서비스 개요

IP담보 자동대출 플랫폼은 중소기업이 보유한 특허권을 담보로 대출을 신청하면 LLM 평가 엔진이 특허 가치평가보고서를 자동으로 만들고, 지정 평가기관의 평가사가 이를 검토·확정한 뒤, 스마트컨트랙트가 담보인정비율(LTV)을 판정하고, 은행 여신담당자가 최종 승인하는 시스템이다. 신청부터 승인·상환까지의 주요 결정은 블록체인에 기록되므로 참여기관이 같은 기록을 확인할 수 있다.

구성 요소역할
웹 서비스차주기업·평가사·여신담당자가 쓰는 업무 화면(https://iploan.mustree.kr)
플랫폼 서버제출 문서 암호화·보관, 평가 접수, 담당자 배정, 블록체인 기록 검증과 화면 동기화
LLM 평가 엔진특허 공고전문 PDF로 평가보고서와 근거자료를 만드는 외부 보고서 생성 서비스
블록체인(Mustsem)신청·평가·승인·상환 기록과 평가 SBT·채권 NFT 발급을 처리하는 스마트컨트랙트
IPFS암호화된 원본 문서와 암호화된 평가 확정 내용을 보관하는 분산 저장소
MetaMask 지갑참여자 본인 확인(서명)과 블록체인 거래 승인에 쓰는 브라우저 지갑
운영 원칙
  • 서버는 참여자의 개인키를 보관하지 않는다. 신청 등록, 평가 확정, 최종 승인·거절, 상환 기록은 각 담당자가 자기 지갑으로 직접 승인한다.
  • 원본 문서는 암호화해 보관하고, 블록체인에는 문서 해시와 저장 위치(CID)만 기록한다.
  • 블록체인 기록이 업무 상태의 최종 기준이다. 화면이 블록체인 기록과 다르면 체인 확인·복구로 화면을 맞춘다.

차주기업은 신청 화면에서 기업정보·특허정보·신청금액·상환 희망 기간(12·24·36개월)을 입력하고 공고전문 PDF 1개(최대 20MiB)를 제출한다. 진행 상황 화면에는 신청 접수 → 서류 검증 → IP 가치평가 → 대출 심사 → 결과의 5단계가 표시된다. 차주기업의 문의를 받으면 이 화면 기준으로 안내한다.

1.5공통 준비사항

접속 환경

  • PC용 Chrome 또는 Edge 브라우저와 MetaMask 확장 프로그램
  • 웹 주소: https://iploan.mustree.kr
  • 담당자 본인 명의의 MetaMask 지갑. 1인 1지갑을 원칙으로 하고 기관 공용 지갑은 쓰지 않는다.

지갑 등록 절차

  1. 담당자가 MetaMask에서 지갑을 만들고 공개 주소(0x로 시작하는 42자리)를 확인한다.
  2. 소속 기관 책임자의 확인을 받아 플랫폼 운영사에 공개 주소와 역할(평가사 또는 은행)을 전달한다. 개인키와 복구 문구는 어떤 경우에도 전달하지 않는다.
  3. 운영사 관리자가 관리자 화면(주소 권한 관리)에서 그 주소에 역할을 부여한다. 역할 부여도 블록체인 거래로 기록된다.
  4. 거래 수수료(가스)로 쓸 MST를 지갑에 확보한다. 시범운영 기간에는 운영사가 지급한다. 협의안
  5. 담당자는 웹 화면에서 지갑 연결과 역할 표시를 확인한다.

네트워크 설정

네트워크 이름Mustsem
체인 ID7601
RPC URLhttps://block.mustree.kr
통화 기호MST

처음 거래를 실행하면 MetaMask가 네트워크 추가·전환을 요청한다. 위 값과 같은지 확인한 뒤 승인한다.

화면 역할 선택

화면 오른쪽 위 사용자 영역을 눌러 역할을 고른다. 여신심사역 · NH농협은행, IP 가치평가자 · 지정 평가기관, 차주기업 담당자 중 하나를 선택하면 왼쪽 메뉴가 역할에 맞게 바뀐다. 역할 선택은 화면 구성만 바꾼다. 실제 처리 권한은 지갑에 등록된 역할과 신청별 배정으로 확인한다.

1.6공통 보안 수칙

  1. 개인키와 복구 문구는 누구에게도 알려주지 않는다. 운영사·은행·평가기관 누구도 이를 요구하지 않는다. 요구를 받으면 즉시 운영사에 신고한다.
  2. 서명·거래 창에서 신청번호, 지갑 주소, 네트워크(Chain ID 7601)를 확인한 뒤 승인한다.
  3. 지갑을 다른 사람과 공유하지 않는다. 퇴직·전보·장기 부재 시 운영사에 권한 회수 또는 배정 제외를 요청한다.
  4. 원본 PDF·평가보고서·재무정보는 업무 목적 외로 저장·복사·전송하지 않는다. 내려받은 파일은 업무가 끝나면 파기한다.
  5. 거래를 처리하는 동안 브라우저의 사이트 데이터를 지우지 않는다. 미확정 거래를 복구할 때 필요한 거래 해시가 브라우저에 저장된다.
  6. 공용 PC에서 지갑을 쓰지 않고, MetaMask 자동 잠금을 설정한다.
